# Era

> Era is an AI-native personal finance platform. Connect your bank accounts to any AI assistant — Claude, ChatGPT, Gemini, Cursor, or any MCP-compatible agent — and manage your money through natural conversation. Available in the US, UK, and Canada.

Era connects to financial institutions via secure integrations and exposes every capability through MCP (Model Context Protocol). Features include spending analysis, cash flow forecasting, automated transaction categorization, custom rules, and personalized financial guidance.

## Context MCP server

- [Context MCP server documentation](https://era.app/help/mcp-server-era-context): Era Context remote MCP server details, Streamable HTTP endpoint, OAuth setup, tool safety boundaries, and workflow recipes
- [Server card](https://era.app/.well-known/mcp/server-card.json): Machine-readable server metadata for MCP directories and compatible clients
- MCP server URL: https://context.era.app — OAuth-protected remote MCP server using Streamable HTTP; the API also accepts the explicit https://context.era.app/mcp endpoint.
- Tool catalog: 65 production-registered tools; up to 63 available to ordinary assistants depending on plan, OAuth scopes, connected accounts, and MCP client support. Catalog generated 2026-07-13.
